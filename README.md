# Lumina
Lumina — це гібридна соцмережа, що поєднує візуальний стиль із текстовими дискусіями.

# Основна суть:
Формат: Фото або відео, які є фундаментом для глибоких текстових гілок .

Інтерфейс: Мінімалістична темна тема з неоновими акцентами та зручним нижнім меню.

## Технологія: Працює на HTML/JS із хмарною базою даних Supabase, що дозволяє бачити пости один одного в реальному часі.

# Головні фішки:
Стрічка: Фокус на контенті без зайвого шуму.

Профіль: Персональна сторінка з твоєю статистикою та історією думок.

Хмара: Твій нікнейм та пости зберігаються на сервері й доступні з будь-якого пристрою.
